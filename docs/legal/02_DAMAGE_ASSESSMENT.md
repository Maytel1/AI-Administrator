# Оценка вреда субъектам ПДн и уровень защищённости — заготовка

> **Не юридическая консультация.** Документ оператора для ИСПДн (требуется для
> классификации и выбора мер защиты по ПП РФ №1119 и методикам ФСТЭК).
> Итогом является уровень защищённости (УЗ) — от него зависят обязательные меры
> защиты. **Готовит вместе с юристом/информационной безопасностью.**

## 1. Описание ИСПДн

- **Назначение:** сервис записи и автоматизации салонов (см. `01_RKN_NOTIFICATION.md`, разд. 6).
- **Размещение:** РФ, Yandex Cloud; СУБД PostgreSQL; объектное хранилище (аудио/транскрипты).
- **Категории обрабатываемых ПДн:** общедоступные (имя, телефон) + переписка + аудио (см. разд. 4 уведомления).
- **Объём:** субъекты — клиенты салонов (тысячи), учётные записи салонов (единицы-десятки).

## 2. Актуальные угрозы (по типам ФСТЭК)

| Тип угрозы | Применимость | Комментарий |
|---|---|---|
| 1-й (внешний, высокий потенциал, спецдоступ) | Базовая оценка | Определяется наличием спец. средств/данных |
| 2-й (внешний, средний потенциал) | **Применим** | Массовый онлайн-сервис, публичный доступ через бота |
| 3-й (внутренний, низкий потенциал) | **Применим** | Доступ персонала/ошибочные действия |
| Спец. угрозы для голосовых данных | Требует оценки | Запись голоса — уточнить признак биометрии |

## 3. Оценка возможного вреда субъектам

| Категория вреда | Описание последствий утечки | Оценка тяжести |
|---|---|---|
| Моральный / репутационный | Раскрытие факта обращения в салон, содержания переписки | Средняя |
| Имущественный | Спам/мошенничество по утёкшим телефонам, фишинг | Средняя-высокая |
| Нарушение неприкосновенности частной жизни | Утечка содержания диалогов/аудио | Средняя |
| Дискриминация / стигматизация | Низкая (целевых спец. категорий нет) | Низкая |

## 4. Предварительный уровень защищённости (УЗ)

- **Предложение (предварительное): УЗ-3** (сервис с общедоступными ПДн клиентов,
  без спец. категорий и биометрии, объём — тысячи субъектов).
- **Повышение до УЗ-2 или УЗ-1** возможно, если аудио признаётся **биометрическими
  ПДн** или если юрист/ИБ скорректируют оценку угроз.
- ⚠️ Этот пункт — решение юриста и ИБ. Не выбирайте УЗ самостоятельно.

## 5. Меры защиты под предлагаемый УЗ-3 (для подтверждения)

- Размещение ИСПДн в РФ; управление доступом по ролям (RBAC); аудит действий.
- Шифрование трафика (TLS) и хранилищ; резервное копирование.
- Назначение ответственного за организацию обработки ПДн; регламент доступов.
- Обнаружение (антивирус), предотвращение вторжений (сетевая сегментация).
- Срок реакции на инциденты: уведомление салона ≤ 24 часа (из договора ПДн).
- Удаление/обезличивание по срокам (аудио ≤ 90 дней, lifecycle).

## 6. Вывод (заполняет юрист/ИБ)

`[УЗ = ___]`. Перечень обязательных организационных и технических мер —
привести в соответствие с выбранным УЗ. Пересматривать при изменении объёмов,
категорий данных или по итогам аудита.
