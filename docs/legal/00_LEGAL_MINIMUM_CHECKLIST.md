# Юр.минимум до первой продажи — чек-лист и статус

> **Не юридическая консультация.** Заготовки для лицензированного юриста
> (методология: скилл `general-counsel-advisor` — «surfaces вопросы, не
> заменяет юриста»). Статусы на 11.10.2026. Документы в этой папке —
> **черновики**, их вычитывает и подаёт юрист.

## Что закрыто (в коде/документах проекта)

| Артефакт | Где | Статус |
|---|---|---|
| Публичная оферта | `/oferta` (legal.py) + реквизиты из `BILLING_*` | ✅ есть, ждёт вычитки юристом |
| Соглашение об обработке ПДн (клиенты салонов) | `/pdn` (legal.py) + CONTRACT_PDN_TEMPLATE.md | ✅ есть, модель «салон=оператор / мы=обработчик» |
| Обязательные согласия при входе (галочки оферта+ПДн) | панель, `login_post` | ✅ есть |
| Единый прайс | billing.price_of → TARIFFS (5/12/15 тыс) | ✅ синхронизировано |

## Что нужно ДО приёма первого клиента (приоритет)

Легенда статуса: **загот.** = черновик в этой папке готов, осталось действие вне кода;
**код** = можно закрыть в проекте; **решение** = выбирает основатель.

- [ ] **1. Уведомление в РКН как оператору ПДн** — `01_RKN_NOTIFICATION.md` (**загот.**)
  (мы оператор для данных учётных записей салонов, биллинга, логов).
  Подача через личный кабинет РКН юристом, **до начала обработки**.
- [ ] **2. Оценка вреда субъектам ПДн** — `02_DAMAGE_ASSESSMENT.md` (**загот.**)
  (обязательный документ оператора; задаёт уровень защищённости ИСПДн).
- [ ] **3. Правовая позиция по трансграничной передаче** — `03_CROSSBORDER_POSITION.md`
  (**загот.** + **решение**: выбрать вариант A/B/C). Переписка идёт через
  Telegram/WhatsApp — вне РФ; договор это отрицает.
- [ ] **4. Назначить ответственного за организацию обработки ПДн** (приказ/должн.
  инструкция) — **можно самим**, это внутренний документ.
- [x] **5. Политика в отношении ПДн** — `05_PDN_POLICY.md` (**загот.**, разместить на
  сайте + ссылка из `/pdn`; вычитать юристу перед публикацией).
- [ ] **6. Согласие клиентов салонов на обработку ПДн** — формулировка + как
  фиксируем (голос/галочка в боте). Частично в `05`; **решение** по механике фиксации.
- [ ] **7. Уведомление «разговор записывается»** — проигрыш в начале звонка
  (голосовой контур) — **код**, можно закрыть в проекте.
- [x] **8. NDA** для пилотных салонов — `04_NDA_PILOT.md` (**загот.**, адаптирован под ГК РФ).
- [x] **9. Пилот-договор, счёт, акт** — `06_PILOT_AGREEMENT.md`, `07_INVOICE_TEMPLATE.md`,
  `08_ACCEPTANCE_ACT.md` (**загот.**). Счёт уже генерируется панелью (`invoice_text`);
  акт — ручной шаблон или автор-генерация.

> **Отдельно — деньги (не в этом чек-листе, но блокирует приём платежа):**
> эквайринга и онлайн-кассы (54-ФЗ) в коде **нет**. На **пилоте с ИП на УСН** это
> обходится приёмом вручную: счёт → перевод по реквизитам → `mark_paid` в панели.
> Для салонов-юрлиц/сетей, которым нужен фискальный чек, понадобится касса —
> это уже **после** первой продажи/пилота.

## Можно после первых клиентов (не блокирует пилот)

- [ ] Регистрация товарного знака (когда выбрано имя).
- [ ] Годовые контракты, порядок паузы в низкий сезон.
- [ ] Резерв под компенсации (если введём вариант 3 из LIABILITY_OPTIONS).

## Комментарий методологии скилла (Output Standard)

**Bottom line:** продукт юридически почти собран — оферта и ПДн-договор есть и
встроены в вход. **Блокирует первую продажу** три операционных документа
оператора (уведомление РКН, оценка вреда, позиция по трансграничке) — они вне
кода и делаются юристом. **Решение основателя:** выбрать юриста (А2 из
GAP_ANALYSIS) и отдать ему три заготовки из этой папки.
