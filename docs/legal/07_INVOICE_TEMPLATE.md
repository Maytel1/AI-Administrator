# Счёт на оплату (формальный шаблон)

> **Не юридическая консультация.** Черновик для бухгалтерии. Панель **уже печатает
> текстовый счёт** автоматически (раздел «Тариф и оплата» / `billing.py` → `invoice_text`),
> но тот рассчитан на ИП/СБП и без НДС. Этот файл — формальный счёт для салонов
> **юридического лица / ИП на ОСНО**, где бухгалтерия требует полный набор. Поля из
> реквизитов (`BILLING_*`) и цены (5/12/15 тыс ₽) совпадают с панелью.
