Единый AI-администратор: текст + голос для салонов красоты

План создания продукта, который закрывает все каналы связи клиента — входящие звонки 24/7 и чаты в мессенджерах — с интеграцией YCLIENTS / DIKIDI (Altegio). Позиционирование и конкурентная рамка — в отчёте COMPETITORS_TYUMEN.html.

Продукт: единый AI-администратор для салонов красоты / барбершопов, который закрывает все каналы связи клиента: входящие звонки (голос 24/7) + текстовые чаты (WhatsApp, Telegram, VK, Instagram Direct). Интеграция с YCLIENTS / DIKIDI (Altegio).

Архитектурный принцип: «один мозг — два рта». Единое LLM-ядро с beauty-логикой (услуги, мастера, слоты, FAQ), к которому подключены два канальных адаптера: телефония (голос) и мессенджеры (текст). CRM-слой записи общий.

Четыре роли YC в проекте. Всё остальное — не Yandex: LLM — OpenAI, телефония — Mango / UIS / Zadarma, мессенджеры — Bot API / BSP, CRM — YCLIENTS / Altegio.

Не брать на горизонте 12–14 недель: Kubernetes и ALB до фазы 5, DataSphere, Managed Kafka, Cloud CDN, BareMetal — лишние расходы.

Новое в YC — может заменить самописный call-service. 28.05.2026 в Yandex AI Studio запущен конструктор голосовых ИИ-агентов (модель Yandex Speech Realtime): существующая АТС подключается по SIP (RTP → платформа), статус — Preview, интеграция через поддержку YC. Плюс — резко меньше разработки, есть Brand Voice Lite (запись своего голоса). Минус — LLM-ядро YandexGPT (не gpt-4o-mini), beauty-логика ограничена их tools-интерфейсом. Действие: запрос в поддержку YC + сравнительный тест с Pipecat-стендом (снимает риск латентности).

Ключевые решения

  1. Один LLM-агент на оба канала — экономия разработки и единая логика ответов.
  2. Голосовой цикл отдельным сервисом (call-service), т.к. там realtime-требования: отклик бота < 1 сек, бардж-ин.
  3. Текстовые боты могут работать даже без LLM на FAQ+кнопках (fallback при недоступности API).
  4. Все данные и логи — в Yandex Cloud (152-ФЗ), записи разговоров храним с уведомлением клиента в начале звонка.

4Этапы 12–14 недель до платного пилота

Фаза 0 — Подготовка неделя 1

Цель: все доступы, ключи и юр. база.

Риск фазы: доступ к партнёрскому API YCLIENTS — самый долгий внешний шаг (от 2 недель). Параллельно готовим Altegio API (доступ быстрее) как первый интегрируемый объект.

Фаза 1 — «Мозг» и CRM-слой недели 2–4

Цель: текстовый агент пишет в CRM, CLI-тесты проходят.

Критерий готовности: 90% тестовых диалогов (сценарный набор ~30 штук) завершается корректной записью в CRM в тестовом салоне.

Фаза 2 — Текстовые каналы недели 5–7

Цель: бот в Telegram и WhatsApp реально записывает клиентов.

Критерий готовности: ≥50 реальных диалогов у пилота, ≥30% диалогов завершаются записью без человека.

Фаза 3 — Голосовой контур недели 7–10

Цель: бот берёт трубку и записывает по телефону.

Критерий готовности: 80% тестовых звонков завершаются корректной записью; средняя латентность ответа < 1.2 сек.

Фаза 4 — Продуктизация и пилот недели 10–12

Цель: продукт можно продать и подключить за 1 день.

Критерий готовности: подключение нового салона ≤ 1 рабочий день, 2–3 платных пилота запущены.

Фаза 5 — Масштабирование недели 12+, после первых продаж

8Партнёрства и доступы — критический путь

  1. Altegio (DIKIDI) API — fastest path: запрос доступа через сайт партнёров, обычно быстрее, чем YCLIENTS. Первый интегрируемый CRM.
  2. YCLIENTS партнёрская программа — заявка на api.yclients.ru; рассматривают интеграционные решения для салонов. Готовим демо текстового бота для ускорения одобрения.
  3. Телефония — договор с Mango Office / UIS / Zadarma (у всех есть API + тестовые номера). Мгновенно, без «партнёрских программ».
  4. WhatsApp BSP — Wazzup (простой старт, RU-поддержка) или 360dialog (официальный BSP). Opt-in клиентов обязателен.
  5. LLM-провайдер — OpenAI платный сразу; на этапе разработки можно тестировать DeepSeek (дешевле), но прод — с SLA.
  6. Дружественные салоны — 2–3 точки Тюмени с договором пилота: доступ к их YCLIENTS/Altegio + телефония в обмен на бесплатный период. Это обходной путь, пока нет партнёрского API.
Самое долгое звено — YCLIENTS. Начинать заявку в фазе 0, не откладывая. Все остальные доступы оформляются за 1–3 дня.
