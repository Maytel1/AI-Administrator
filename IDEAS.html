1Спецификация продукта (уточнено)

Суть: голосовой AI-администратор для МСБ услуг Тюмени. Стартовые вертикали (29.09.2026): автосервисы + стоматологии + бьютисфера (салоны красоты и барбершопы — beauty-фокус сохранён). Перехватывает звонок и ведёт диалог с клиентом вместо живого администратора.

Функции:

  1. Перехват звонка — приём входящего звонка (в т.ч. когда салон занят или закрыт).
  2. Общение с клиентом — естественный диалог, ответы на вопросы.
  3. Объяснение услуг — рассказ об услугах, ценах, мастерах, акциях.
  4. Обработка запроса — выявление потребности клиента.
  5. Запись посещения — бронирование даты, времени, услуги, мастера.
  6. Создание записей в календаре работника — запись в календарь; провайдер календаря подключается позже и может быть любым (нужна абстракция/адаптер).
  7. Контроль записей — учёт, изменение, отмена, напоминания, недопущение накладок.

2Рантайм

  • Агент: Cline (VS Code)
  • Модель: DeepSeek
  • Важно: Agent Skills — нативный формат Anthropic и не загружается моделью автоматически. Поэтому скиллы зарегистрированы через .clinerules (эмуляция поведения Agent Skills для Cline + DeepSeek).

3Регистрация скиллов

  • Правило Cline: C:\Users\1\Desktop\.clinerules\skills.md — инструкции по загрузке и полный индекс всех 495 скиллов с путями и триггерами. Cline подгружает это правило автоматически в начале каждой задачи.
  • Индекс (Markdown): project/skills/INDEX.md — человекочитаемый индекс.
  • Индекс (JSON): project/skills/skills.json — машинный список (name, set, path, description).
  • Генераторы: project/build_skill_index.py и project/build_clinerules.py — пересборка индекса и правила (запуск: python project\build_skill_index.py, затем python project\build_clinerules.py).

4Обслуживание скиллов

  • Очистка дублей: python project\cleanup_duplicates.py (сначала --dry-run). Удалено 617 дублирующих директорий (~1488 файлов, 12.7 МБ) — агент-специфичные копии .gemini, .claude, .codex, .cursor, .windsurf и плагинные дубли.
  • Проверка работоспособности: python project\validate_skills.py — проверяет наличие файла, frontmatter (name/description), непустоту. Результат последнего прогона: 495/495 OK, проблем 0.

6Исследование ниши: администраторы (Тюмень, сентябрь 2026)

Источник: открытые данные Роструда (Trudvsem API, регион 7200000000000). hh.ru API из сети недоступен (403 / код 000). Скрипты: research_trud.py, analyze_trud.py. Данные: trud_admin_tyumen.json, отчёты: trud_report.txt, trud_analysis.txt.

Цифры (актуальные, обновлены за 30 дней)

  • Ниша по области (администратор / ресепшн / секретарь / оператор / диспетчер / регистратор / офис-менеджер): 303 вакансии.
  • Город Тюмень: 148.
  • Без крупных сетей (МСБ): 64.
  • Сфера услуг (салон / клиника / отель / автосервис / фитнес / образование / недвижимость): 47.
  • С привязкой к звонкам/записи клиентов: 31.

Требования нанимателей

  • Опыт: ~70% — опыт НЕ требуется (0 лет) либо достаточно 1 года. Образование: среднее / среднее специальное.
  • График: сменная работа (~50%), полный день (~35%).
  • Частые требования: работа с клиентами, приём и распределение звонков, ведение записей, работа с ПК/программами, консультирование, контроль порядка.
  • Зарплата (город, МСБ): от 29 880 руб., медиана 38 000 руб.

Проблема с данными

Trudvsem переполнен бюджетниками (больницы, МФЦ, суды) и крупной розницей (Fix Price, Пятёрочка) — малый/средний бизнес услуг (салоны, частные клиники, отели, автосервисы) там представлен слабо. Основной пул МСБ — на hh.ru, Avito, Работа.ру; нужен дополнительный источник.

Выводы

  • Ниша реальна и объёмна: только в Тюмени десятки актуальных вакансий администратора в МСБ услуг.
  • Типовой портрет: без опыта, сменный график, приём звонков + запись клиентов + работа с программами, зарплата ~38 000 руб.
  • Задачи повторяемы (звонки, запись, консультирование) -> поддаются систематизации.

9Принятые решения

  • Источники данных: hh.ru из этой сети недоступен (API 403, web 302). База — Trudvsem; качественные данные собирать вручную с hh.ru/Avito/Работа.ру.
  • Приоритетная сфера (клин) — обновлено 29.09.2026: три вертикали: автосервисы + стоматологии + бьютисфера (салоны красоты/барбершопы — beauty-фокус сохранён).
  • Формат продукта: голосовой AI-администратор (не человек+софт): перехват звонка, диалог с клиентом, объяснение услуг, обработка запроса, запись посещения, создание записей в календаре работника (провайдер календаря — позже, через адаптер), контроль записей. Полная спецификация — в начале файла.
  • Модель оплаты: подписка за салон (фикс в месяц), ценность = спасённые звонки и предотвращённые неявки.
  • Custdev: 10–15 интервью по Mom Test с владельцами салонов.

Решения от 20.09.2026 (после ответов на 28 вопросов)

  • Голос и образ: женский голос, один на всех, максимально «очеловеченный»; бот представляется живым администратором (уведомление о записи разговора сохраняется; честный ответ на прямой вопрос «вы робот?» — риск в DEVELOPMENT_PLAN.md, раздел 5).
  • Клиенты: бот узнаёт своих клиентов по номеру телефона (история визитов, скидки, любимый мастер — из CRM).
  • Предоплата: опциональная функция на уровне клиента — флаг «требует предоплату» в ЛК, бот предлагает внести предоплату (платёжная ссылка) или отказаться; включается владельцем салона на каждого клиента отдельно.
  • Условия покупки: setup платный; 7 дней тарифа бесплатно; далее подписка; тариф можно менять в любой момент с перерасчётом. Сетка — на согласовании: project/TARIFFS.md.
  • Личный кабинет: обязателен для каждого подключённого салона; плюс веб-админка для нашей команды; требования безопасности — DEVELOPMENT_PLAN.md, раздел 8.2.
  • Подтверждение клиенту: SMS + уведомление в мессенджере (VK/WhatsApp/Telegram по доступному каналу).
  • Юрлицо и ПДн — обновлено 29.09.2026: самозанятость (НПД) без ИП, без ПСН/патента; договор поручения на обработку ПДн — шаблон project/CONTRACT_PDN_TEMPLATE.md; салон имеет доступ к записям звонков.
  • Продажи и рост: продаёт лично владелец проекта (включая встречи на точках по следам вакансий); базовая линия «до» — отчёты YCLIENTS или статистика АТС; рефералка — месяц тарифа бесплатно за приведённого и подключившегося.
  • Поддержка: ночные алерты на владельца проекта, обрабатывает он же; днём — эскалация человеку.
  • Отложено: ров за пределами Тюмени и экспансия (соседние города) — не сейчас; сбои — project/FAILOVER_SCENARIOS.md; ПДн/LLM — project/PDN_LLM_OPTIONS.md; WhatsApp-миграция, бренд, TAM — project/OPEN_QUESTIONS.md.
  • Рободо-звон: подробное объяснение отправлено в чате; решение — за владельцем (см. PLAN.md).
