# Миграции

- Свежая БД: схема поднимается автоматически при первом старте контейнера
  (`docker/postgres/init/001–004` через `docker-entrypoint-initdb.d`).
- Последующие изменения: добавляйте сюда `005_<описание>.sql` — рантайм
  `admin_core.db.run_migrations` применит их по таблице `schema_migrations`
  при старте `cli`/сервисов и пометит применёнными.
- Базовая линия (001–004) помечается автоматически при первом запуске на уже
  инициализированной БД.
