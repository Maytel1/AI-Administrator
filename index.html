Как смотреть на GitHub

GitHub Pages (1 минута, бесплатно): в репозитории откройте Settings → Pages, в «Build and deployment» выберите Source: Deploy from a branch, Branch: main, папка / (root), нажмите Save. Через минуту этот индекс откроется по адресу https://<логин>.github.io/<имя-репозитория>/ — все ссылки на документы относительные и заработают сразу. Файл .nojekyll уже в репозитории (отключает сборку Jekyll). Для приватного репозитория Pages доступен только на платных планах.

Без настройки Pages: на странице файла GitHub показывает HTML как код — это нормально. Быстрый предпросмотр: https://htmlpreview.github.io/?https://github.com/<логин>/<репозиторий>/blob/main/index.html. Полная инструкция — в README.md.
